# Portfólio — Matheus Barros

Landing page estática baseada no conteúdo público do perfil
[@matheusfotografiasz](https://www.instagram.com/matheusfotografiasz/).

## Executar localmente

```bash
python3 -m http.server 4173
```

Abra `http://127.0.0.1:4173` no navegador.

O formulário não envia dados para um servidor: ele prepara uma mensagem para o visitante
copiar e enviar pelo canal oficial do Instagram.
