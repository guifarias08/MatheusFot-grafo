# Portfólio — Matheus Barros

Landing page estática baseada no conteúdo público do perfil
[@matheusfotografiasz](https://www.instagram.com/matheusfotografiasz/).

## Executar localmente

```bash
python3 -m http.server 4173
```

Abra `http://127.0.0.1:4173` no navegador.

Os pedidos de orçamento seguem diretamente para o canal oficial do Instagram.

## Imagens adicionais

As imagens `andreia-30-decor.webp`, `lucca-familia-2.webp` e
`hadassa-15-detalhe.webp` foram selecionadas dos álbuns do Google Drive fornecidos
para este projeto e convertidas para WebP. A confirmação final de autorização de
publicação deve ser feita pelo fotógrafo antes de colocar o site no ar.

O álbum de Júnior & Milli permanece vinculado no catálogo. Nesta revisão, foram
usadas somente imagens locais já disponíveis para esse projeto, pois os primeiros
arquivos retornados pela pasta compartilhada não correspondiam visualmente ao casal.

## Galeria editorial — 11/11/2026

O site foi reduzido a duas partes: uma apresentação direta do Matheus com foto real e uma
galeria editorial de serviços. Casamentos, aniversários, ensaios e eventos aparecem em uma
grade assimétrica, com filtros e álbuns completos em uma janela visual. A tipografia usa
Instrument Serif para títulos e Manrope para interface. A paleta recupera a identidade do
primeiro modelo, com preto `#11110F`, creme `#F6F3ED`, coral `#F05A43` e verde-claro
`#DFE6A0`.
