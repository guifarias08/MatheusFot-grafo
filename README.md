# Portfólio — Matheus Barros

Landing page estática baseada no conteúdo público do perfil
[@matheusfotografiasz](https://www.instagram.com/matheusfotografiasz/).

## Executar localmente

```bash
python3 -m http.server 4173
```

Abra `http://127.0.0.1:4173` no navegador.

O contato segue diretamente para o canal oficial do Instagram.

## Imagens locais

As imagens `andreia-30-decor.webp`, `lucca-familia-2.webp` e
`hadassa-15-detalhe.webp` foram selecionadas dos álbuns do Google Drive fornecidos
para este projeto e convertidas para WebP. A confirmação final de autorização de
publicação deve ser feita pelo fotógrafo antes de colocar o site no ar.

Os projetos são mantidos em `data/portfolio.js` e exibidos somente com arquivos locais.
Não há links de Drive na interface.

## Galeria documental — 13/11/2026

A página ficou reduzida ao essencial: uma apresentação do Matheus, uma galeria contínua de
trabalhos e um bloco simples sobre ele. A foto real da abertura aparece inteira, sem o recorte
que escondia a câmera e o corpo. Todos os registros dos projetos entram no mosaico, sem cards,
títulos ou textos sobre as imagens.

A identidade usa carvão, areia e terracota suave para manter a leitura fotográfica e discreta.
As entradas do hero, a revelação progressiva do mosaico, o movimento sutil do cursor e a
transição do visualizador seguem um ritmo editorial, sem copiar a paleta da referência. O site
continua em HTML, CSS e JavaScript vanilla, com filtros e um visualizador imersivo para toda a
sequência de fotos.
